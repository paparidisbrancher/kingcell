# King Cell | Machado

Site estático da King Cell, unidade Machado (MG). HTML + CSS puros, sem build e sem dependências.
Publicado no GitHub Pages: https://paparidisbrancher.github.io/kingcell/

## Pendências (dados que a loja precisa fornecer)
- Confirmar os WhatsApps das 5 unidades e o nome completo da cidade "Conceição".
- Endereço, horário de atendimento, CNPJ e razão social (para rodapé, mapa e dados estruturados).
- Logo vetorial (SVG/PDF); hoje só há versões raster pequenas.
- Políticas de garantia, troca e devolução.
- Fotos próprias em alta resolução (fachada e produtos).
- Autorização de uso das imagens das publicações de @davifernandes.gestor e @kauecarvalh_.
